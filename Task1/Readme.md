## 3. Карта интеграций

Вкладка **«Карта интеграций»** (`integration_map.png`).

### Ключевые потоки

| Откуда → Куда                 | Что передаётся                    | Тип интеграции |
|-------------------------------|-----------------------------------|----------------|
| Интернет-банк → АБС           | Прямой SQL-запрос                 | 🔧 tight-coupling |
| Сайт → Система КЦ             | Заявка на депозит (REST)          | API           |
| Система КЦ → АБС              | Создание заявки (API)             | API           |
| АБС → SMS-шлюз                | СМС-уведомление клиенту           | SOAP/SMPP     |
| Excel / Почта → АБС           | Ставки / согласования             | **ручной**    |
| Партнёр КЦ → Система КЦ       | Лиды (CSV по SFTP)                | **ручной**    |

### Легенда цветов и линий

| Элемент                   | Обозначение |
|---------------------------|-------------|
| Голубой прямоугольник     | Внутренняя система банка |
| Жёлтый прямоугольник      | Внешняя система партнёра |
| Красный прямоугольник     | Ручной процесс / офисные инструменты |
| **Сплошная стрелка**      | Автоматическая интеграция (API, SQL) |
| **Пунктирная стрелка**    | Обмен файлами / ручной ввод |

## 4. Основные проблемы «as-is»

1. **Ручной расчёт ставок** (Excel + почта) ⇒ нет real-time, высокий риск ошибок.
2. **Прямой SQL из интернет-банка в БД АБС** ⇒ сильная связка, возможные сбои учёта.
3. **Human-in-the-loop** между фронтом и бэк-офисом ⇒ клиент ждёт 20–60 минут.
4. **Нет единой шины/ESB** ⇒ point-to-point «лапша», сложно версионировать.
5. **Разрозненные каналы продаж** (сайт / ИБ / КЦ) ⇒ данные не консолидируются.
